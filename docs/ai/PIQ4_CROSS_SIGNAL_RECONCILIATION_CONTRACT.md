# PIQ-4.2 — primary goal / experimental evidence / performance reconciliation

This is a read-only current-day **reasoned attention ordering**, not a
maintenance intervention gate. Inputs are the existing revision-checked
current settings, owner primary-goal selection, versioned goal boundary
observations, exercise performance safety review, Personal Lab timing and
typed outcome relevance, recent finalized result readiness, and source-matched
protein/training context.

The pure reconciliation prioritizes (1) missing/changed sources, (2)
contradiction where owner-selected active weight goal has no matching active
weight goal in the independent read, (3) explicitly cleared/unset/non-weight
priority, (4) possible exercise decline, (5) active or soon-scheduled
experiments and finalized direct observations, and then (6) **descriptive
alignment only**. Every state has `calorieAdjustment=not_authorized`,
`plateauClassification=not_authorized`, `strengthPreservation=not_verified`.
An interpretable result is not linked to today's goal version as a causal
effect; a valid weight measurement is not canonical unmet-goal status; no
decline flag is not proven muscle preservation; the configured nutrition
target is not an adequacy screen. Source missingness never means absence.

Only code-like reason IDs, aggregate state and non-substantive text enter the
packet, not private goal IDs, experiment IDs, caloric amounts, exact protocol
criteria or strength measurements. This slice does NOT implement clinical
recommendations, new SQL, migrations, paid model calls or deployment.

Remaining scope: owner-accepted adjudication of goal urgency/direction,
action gates in the canonical maintenance path, and end-to-end live-owner QA.
